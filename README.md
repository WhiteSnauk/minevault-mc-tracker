# ⛏️ MineVault — Игровой органайзер и база знаний для миров Minecraft

**MineVault** — клиент-серверное веб-приложение в пиксельно-блочной стилистике игры Minecraft для систематизации, хранения и быстрого поиска игровых данных, привязанных к конкретному одиночному миру или многопользовательскому серверу.

## ❗ Решаемая проблема
При длительной игре в Minecraft (особенно на серверах и крупных модпаках) игроки теряют важные координаты (`X, Y, Z`), заметки, списки совместимых модов, сиды и контакты участников из-за хранения информации в разрозненных текстовых файлах, скриншотах и внутриигровых книгах.

## 🎯 Цели разработки
* Обеспечить централизованное облачное хранение игровых данных с привязкой к конкретному миру или серверу.
* Сократить время поиска координат и параметров сборки за счёт структурированных форм и фильтрации по измерениям.
* Создать тематический пользовательский интерфейс с поддержкой персонализации (смена фона, профиль, фоновый аудиоплеер).

## ✨ Основные возможности
* **Каталог миров и серверов:** учёт Singleplayer и Multiplayer площадок (версия, ядро, сид, IP-адрес).
* **Навигационный журнал:** хранение координат `X, Y, Z` по измерениям (*Overworld*, *The Nether*, *The End*) со встроенным конвертером `1:8`.
* **Заметки и пользовательские переменные:** ведение планов построек и произвольных параметров формата `Ключ — Значение`.
* **Реестр модов и игроков:** фиксация установленных модификаций с версиями и списка участников сервера.
* **Персонализация и атмосфера:** профиль аккаунта, настройка фоновой панорамы и встроенный музыкальный плеер.
* **Экспорт и публичный доступ:** выгрузка данных мира в `JSON`/`TXT` и просмотр публичных серверов по ссылке.

## 🛠️ Используемые технологии (планируемый стек)
* **Frontend:** HTML5, CSS3 (пиксельная стилизованная вёрстка), JavaScript (ES6+) / React (Vite).
* **Backend:** Node.js, Express (REST API).
* **База данных:** PostgreSQL / SQLite.
* **Инструменты проектирования и контроля версий:** Git, GitHub, UML (Use Case).

## 👥 Пользовательские роли
* **Гость (Guest):** просмотр публичных карточек серверов, прослушивание демо-треков, регистрация и вход.
* **Авторизованный пользователь (Player):** полный CRUD-доступ к своим мирам, координатам, заметкам, спискам модов и настройкам профиля/фона.
* **Администратор (Admin):** модерация публичных карточек, управление учётными записями и системными библиотеками фонов/треков.
